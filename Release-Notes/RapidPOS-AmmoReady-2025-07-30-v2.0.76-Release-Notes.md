# Rapid POS AmmoReady Integration v2.0.76 Release Notes  

*Release Date: July 30, 2025*

---

## What's New

### AmmoReady
- BUGFIX: Editing an order in Counterpoint that is not marked as Order Fulfilled in AmmoReady will now raise an error and not allow the edit to proceed.
- BUGFIX: Fixed an issue where releasing an order in Counterpoint, when it's not marked as Order Fulfilled in AmmoReady, would raise an error but still release the order. This has been corrected.
